# 🔭 Current Focus & Enterprise Buildout

- 📊 **BOOST Mobile & Agile Hub Platform** *(Agile Consulting)*
  * **Mobile Lead:** Designing and developing an offline-first **React Native (Expo)** app for BOOST beneficiaries and small business operators.
  * Local persistence (SQLite) and background delta sync of field financial records, revenue, cash flow, and multi-year projections to a **FastAPI** and **PostgreSQL** backend.
  * **Agile Hub:** a **Django** web platform for hub management covering sales, sales-agent commissions, inventory, payroll, finance, members, services, and reporting. Built with hub-first scoping (each hub sees only its own records), role-based access, spreadsheet imports and exports, and CI checks on every push.
  * 🌐 **Live Demo:** [agile.roberms.com](https://agile.roberms.com/)
  * Next up: offline PWA support (service worker and IndexedDB queue) and yield and demand forecasting reports.

- 🎙️ **LecturerMind Mobile App** *(Flagship AI Project)*
  * Built with **React Native** and **FastAPI**, with a WebSocket audio pipeline.
  * **Deepgram API** for real-time lecture voice-to-text.
  * **Anthropic** and **Gemini** APIs, with pgvector RAG, to generate structured short notes and exam-ready quizzes.

- 📱 **SMS Forwarder Mobile Utility** *(Roberms Ltd)*
  * React Native app with a native **Kotlin** pipeline (broadcast receiver and WorkManager) that forwards SMS reliably in the background, with device-scoped isolation.
  * **FastAPI** backend with a real-time WebSocket dashboard and a retry-send feature.
  * 📄 **API Documentation:** live deployment docs [here](https://smsapi.roberms.com).

- 🏦 **Sacco Mobile App** *(Roberms Ltd)*
  * React Native (Expo Router, TypeScript) member portal for a savings cooperative.
  * Biometric login, OTP flows, M-Pesa payments, loan calculator and loan applications.

- 💬 **WhatsApp AI E-Commerce Assistant**
  * **FastAPI**, **Gemini**, and the Meta WhatsApp Cloud API, with a React admin dashboard.
  * JWT role-based access, variant-level stock, M-Pesa payments, and a full automated test suite.

- 🏠 **Student House Booking Platform**
  * **Django** backend with a **Vite** frontend and M-Pesa payments. Includes messaging, maintenance requests, and lease e-signing.

- 🏗️ **Construct360**
  * **Django** project with a budgets module that generates Bill of Quantities (BOQ) Excel exports, with Gemini integration.
